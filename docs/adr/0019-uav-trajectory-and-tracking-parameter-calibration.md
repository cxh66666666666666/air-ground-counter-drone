# 无人机轨迹与跟踪参数标定（含 C1 修订）

## Status
accepted

## 背景与决策

契约硬约束 **C1** 原文为「8 字轨迹全程恒速、无加减速；角速度 0.1（线速度 0.3 m/s）」。核对旧树后确认两项问题：

1. 旧项目名为"8 字"的实为 `fixed_horizontal`（**两半圆 + 两直线**，`r=3`、`ω=0.2`、`v=0.6`），**并非真八字**；C1 的 `ω=0.1`/`v=0.3` 数字由 `ω·r = 0.1×3.0` 反推而来，描述的正是这一非真八字形态。
2. 旧项目的距离 / 速度参数**偏离真实工程量级**（standoff `2.0/3.5 m`、目标巡航偏慢），不足以支撑"贴近真实"的仿真。

据此定：

- **"8 字"改为真八字（Gerono）**：`x = cx + rx·sinθ`、`y = cy + ry·sinθ·cosθ`（自交成 ∞），`rx=15`、`ry=9`、`h=2.5 m`；**全程恒速 `v=2.0 m/s`（弧长参数化，无加减速）**；**删去"角速度 0.1"**。
- **作业区放大到 80×80 m**（地面 200×200 不变），`agc_car`/`intruder_uav` spawn 分离 **~30 m**，容纳真八字足迹。
- **standoff 安全间距带 `8/15 m`**（水平），跟踪高度 `2.5 m`，滞回 ~1.0 m，最大水平速度 `2.0 m/s`；目标巡航（W3 临时脚本）`1.0 m/s`。
- **参数溯源原则**：距离 / 速度参数取自**权威参考**而非旧项目——PX4 Follow-Me 保距默认 **8 m**；轻小型旋翼机间水平间隔标准 **≥15 m**（T/AOPA）；Nav2 以**倍数 / 时间窗**表达安全距离（`inflation 3.18×半径`、`time_before_collision 1.2–2.0 s`）；室内四旋翼实测速度上限 **1.2–2.0 m/s**。详见 W3 spec 与 `config`。

## Considered Options

- **保留旧 `fixed_horizontal`（半圆 + 直线）** —— 被否：非真八字，几何上不成立。
- **保留 C1 原数值（`ω=0.1`、`v=0.3`、`r=3`）** —— 被否：尺寸 / 速度不切实际，且与真八字不兼容。
- **维持小场地 + 按比例缩放参数** —— 被否：用户要求贴近真实间隔，故放大作业区。
- **沿用旧 `air_follow` 的 `safe_min=2.0`** —— 被否：间距过近，旧项目在此问题突出。

## Consequences

- 契约 [硬约束](../ROS2迁移交接文档.md#hard-constraints) **C1 改写**（真八字 + 恒速 `v=2.0`，删"角速度 0.1"）；此为契约真源变更，先例见 [ADR-0017](./0017-air-ground-collaboration-loop.md) 改写 C10。
- 触发 **W2 打补丁**（作业区放大 80×80、spawn 分离、柱重排）。
- W3 spec 的 R5（轨迹）/R6（standoff）参数据此；`ε`/`ε′` 首轮实跑后回填。
- 与 [ADR-0017](./0017-air-ground-collaboration-loop.md) 一致：C10 的"安全间距"由本条给出**可验证数值**。

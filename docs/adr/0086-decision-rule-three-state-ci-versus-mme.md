# 判据语义修正：分离「最小有意义收益」与「样本量可检测效应」，判定改三态（CI vs MME）

## Status

accepted

## Date

2026-10-23

## 背景

P1 v5（`w7-rl-b/20261023-w7-rl-b-p1v5-n20`，[ADR-0085](0085-w7b-p1-mechanism-activating-scenario-pilot.md)(h)）按当时预注册口径判为"证伪（未达 MDE）"：primary `fire_control_opportunity_rate_active` 均值配对差 **+0.0804**、95% CI **[+0.0281, +0.1328]**、p=0.0046。该判定**使用**的规则是"双侧配对 t 的 `p < α` **且** `mean(Δ) ≥ MDE=0.10`"。

审计发现该规则把**两个统计上不同的角色**压在了同一个数（0.10）上：

1. **样本量规划参数**——"N=20 在 α=0.05 / power=0.80 下能检测到多大效应"（由 α、power、SD、N 决定，是**算出来的**）；
2. **判定通过门槛**——"实测均值差必须 ≥ 0.10 才算成立"（是**研究/工程意义的裁定**，不是算出来的）。

由此产生的**错误读法**：v5 的 CI **包含** 0.10（区间 [+0.0281, +0.1328]），它同时与"真实收益 < 0.10"和"真实收益 > 0.10"相容 ⇒ `mean(Δ)=0.0804 < 0.10` **只能**推出"**未能确认收益达到 0.10**"，**不能**推出"真实收益低于 10 pt"。"证伪"作为标签在语义上**过强**。

**历史纪律**：v1–v5 已执行的 verdict 字段**不改写**（它们是各自口径下的记录）；本节只做**语义澄清**与**新版本规则**，并给出 v5 在该新语义下的**事后读法**（明确标注为解读、非判定证据）。

## 决策

### (a) 术语与角色分离（新版本预注册 **SHALL** 分列两个量）

| 量 | 字段 | 角色 | 来源 |
|---|---|---|---|
| **最小有意义收益（MME / MCID）** | `decision.<命题>.minimum_meaningful_effect` | **决策门槛**：低于此量级的收益在项目意义下不值得主张 | 研究 / 工程意义的**显式裁定**（不随数据变） |
| **样本量可检测效应（规划量）** | `statistics.<命题>.planning.*` | **仅规划**：给定 α / power / σ / N 能检测到的最小效应 | 由 `(z_{1−α/2} + z_{1−power})·σ/√n` **计算** |

**禁止**把两者写进同一字段、或用后者当判定门槛（v1–v5 的旧口径保留为 `legacy_criterion` 记录，仅历史）。

### (b) 判定改**三态**（对 primary DV；按 95% CI 与 MME 的关系）

| 判定 | 判据 | 含义 |
|---|---|---|
| `supported`（成立） | **CI 下限 > MME** | 收益**达到**最小有意义量 |
| `falsified`（证伪） | **CI 上限 < MME** | 可**排除**"收益达到 MME"——真实效应低于门槛 |
| `inconclusive`（未通过门槛） | CI **覆盖** MME | 既**未支持**也**未排除**；须报告点估计 + CI + **决断所需 N** |

等价表述：`supported` ⇔ 对 MME 的**单侧检验** p < α（`H₀: Δ ≤ MME`）；该单侧 p 一并报告。secondary DV 仍只报告、不参与判定。

### (c) v5 的正确读法（**事后解读**，历史 verdict 原文保留）

- v5 primary：Δ=+0.0804、CI [+0.0281, +0.1328] ∋ 0.10 ⇒ **`inconclusive`（未通过门槛）**；**不得**读作"真实收益 < 10 pt"（那需要 CI 上限 < 0.10），**亦不得**读作"收益达到 10 pt"（CI 下限 0.028 < 0.10）。
- 旧记录"证伪（未达预注册 MDE）"**保留原文**并**须附本节读法**；[ADR-0071](0071-w7b-adjudication-record-and-pending-arms.md)(l) / [ADR-0085](0085-w7b-p1-mechanism-activating-scenario-pilot.md)(h) 已按此标注。
- **P2 v3 复核（顺带）**：其 primary CI **[−0.0971, −0.0151]** **完全低于** MME=0.10 ⇒ 三态规则下仍为 **`falsified`**，**结论不变**（且此为 CI 判据，比旧"均值 ≥ MDE"更严谨）。

### (d) 样本量规划的显式化（"样本量可检测的效应"）

要在 `power` 下**支持**"Δ > MME"，需要真实效应与门槛之间有余量：

```
n ≈ ( (z_{1−α/2} + z_{1−power}) · σ / (Δ_true − MME) )²         （双侧 CI 口径）
```

以本项 σ≈0.112（v5 实测配对差 SD）计，所需**配对数**：

| MME | Δ_true = MME+0.02 | +0.03 | +0.04 | +0.05 |
|---|---|---|---|---|
| 0.05 | 246 | 109 | 62 | 39 |
| 0.08 | 246 | 109 | 62 | 39 |
| 0.10 | 246 | 109 | 62 | 39 |

（表中数值只随**余量** `Δ_true − MME` 变化；每对 ≈ 2 episodes ≈ 3–6 min 墙钟 ⇒ N=100 量级 ≈ 5–10 h。）

**设计含义**：MME 越接近预期真实效应，决断所需的 N **非线性增长**；"规划可检测效应"（N=20、σ=0.112 ⇒ 双侧口径 ≈0.070）**小于** MME=0.10 时，典型结局就是 **`inconclusive`**——这是**设计选择的结果**，不是数据异常。

**"可检测"不等于"能通过门槛"（[ADR-0088](0088-mme-change-governance-independent-justification-and-seed-isolation.md)）**：`detectable_effect_two_sided` 是"给定 α / power 能检测到非零效应"的最小量，**不是**"样本均值 ≥ MME"的通过概率。若沿用 legacy `mean ≥ MME` 规则，真实效应恰等于 MME 时通过概率仅约 **50%**（均值抽样以 MME 为中心）；要达到 `power`，需 `Δ_true ≥ MME + z_{power}·σ/√N`。因此**不得**用"N=20 可检测 ≈0.072"论证"能通过 0.08 门槛"。

### (e) 适用范围与禁止事项

- 三态规则适用于 **v6 起的新预注册**；`proposition_versions` 升为 `{p1: 6, p2: 6}`。
- **禁止**用新规则**回溯**改写历史 verdict；也**禁止**把"事后解读"当作判定证据。
- 任何**新的判定**（含在同一场景上取得 `supported`/`falsified`）**SHALL** 由**新预注册 + 新 run** 承载；阈值 / MME / N / 场景在 run 前写定。
- W8 冻结 **SHALL** 使用三态语义与"MME 与规划量分列"的口径。

## 备选

1. **维持"均值 ≥ MDE"** —— 否决：该式不是统计检验（未对抽样不确定性作推断），且把规划量与决策门槛混为一谈（本 ADR 背景节）。
2. **只报 CI、不给判定** —— 否决：违背 [ADR-0070](0070-w7b-research-propositions-and-rl-role-adjudication.md)(h) 的"预注册可判定"要求。
3. **把 MME 下调到 0.08 使 v5 变 `supported`** —— 否决：**事后改门槛**（[F-13](../reviews/agc-review-2026-10-14/30-未来.md#f-13)）；若要更小 MME，须**新预注册**并按 (d) 重新规划 N。
4. **改写 v5 的历史 verdict 字段** —— 否决：证据不可回溯改写；只加"读法"标注。

## 后果

- **正面**：判定与规划的角色不再混淆；`inconclusive` 成为**一等结果**（附"决断所需 N"），避免把"证据不足"误报为"效应不存在"；P2 的既有结论在新规则下**更严谨地保持不变**。
- **代价 / 限制**：v5 的状态需在其记录上**补读法**（不是改判）；后续若要 `supported`/`falsified`，成本按 (d) 的表增长（N≈39–246，取决于门槛-效应余量）。
- **未决 / 后续**：**v6 的 MME=0.10 与三态规则不变**；任何降低 MME 的版本顺延为 **v7**，须满足 [ADR-0088](0088-mme-change-governance-independent-justification-and-seed-isolation.md)（独立工程依据 + 新种子 seeds ≥20 + 按实际规则重算 N）；是否对 s15 做**确认性重跑**以获得三态判定；P2 消融与 W7-c 未执行。

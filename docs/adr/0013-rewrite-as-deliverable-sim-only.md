# 重写即交付物：软著/平台，论文产出于纯仿真

## Status
accepted

## 背景与决策
本项目（大创）的软件交付物**就是本仓库本身**，而非另立的系统：

- **软著登记对象** = 本仓库 `src/` 下的包；
- **"平台搭建"交付物** = 本**仿真**平台（世界 + 车 + 无人机 + 协同栈），非实物平台；
- **论文素材** = 本仓库的仿真实验产物（`experiments/`）；论文在本仓库内完成。

原依托的硬件拦截平台与研究生团队**已撤离**，项目**完全依托仿真**：

- "移动式反无人机平台"等物性对象在仿真中以 GZ Sim 模型 / 插件表达；
- **电磁干扰 / 物理拦截**类操作：**若在仿真中可实现**（先按 [AGENTS](../../AGENTS.md) 的"先学后做"核查既有做法，再定抽象层级），则纳入范围；否则不做（**待定**）。
- 保留未来加载到实机的选项，但**以仿真为重心**——与 [ADR-0009](./0009-sim-first-with-hardware-hooks.md) 一致（预留可替换接口，不承诺支持真机），故 ADR-0009 维持不变。投入力度定为**轻量**：只保持**算法 / 接口边界整洁**以便日后迁移，**不建完整抽象层**。

## Considered Options
- 重写仅作研究载体、软著 / 平台另立一套 —— 被否：实际交付物就是本仓库；拆分会使论文、软著、平台三者口径彼此漂移，且已无实物平台可拆。

## Consequences
- 软著、平台、论文三者**共用同一份代码与产物**；接口语义与终态口径一律以契约真源为准，**不得为凑交付物而分叉**。
- 申报书的"研究进度安排（阶段）"**不作为执行约束**（用户明示无意义）；执行节奏以 [Runbook](../ROS2迁移步骤.md) 的 workstream 与依赖图为准。
- 契约真源 [终态语义](../ROS2迁移交接文档.md#terminal-semantics) 中**悬空的"阶段 A"引用**，需在"干扰/拦截范围"定案后消解（定义或删除）。

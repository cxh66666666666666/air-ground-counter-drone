# MME 变更治理：独立工程依据、种子隔离与按判定规则重新规划

## Status

accepted

## Date

2026-10-24

## 背景

P1 v5（`w7-rl-b/20261023-w7-rl-b-p1v5-n20`）在 [ADR-0086](0086-decision-rule-three-state-ci-versus-mme.md) 的三态规则下为 **`inconclusive`**：primary Δ=+0.0804、95% CI [+0.0281, +0.1328]、MME=0.10。

[ADR-0085](0085-w7b-p1-mechanism-activating-scenario-pilot.md)(h) 曾提出"若项目认为更小效应有意义，可在新预注册中把门槛写定为 ≤0.08"的可能性。该表述有**两个问题**，本 ADR 予以纠正：

1. **编号冲突**：ADR-0085 所说的"v6"已被 [ADR-0086](0086-decision-rule-three-state-ci-versus-mme.md) 用作**三态判据**版本（`proposition_versions: {p1: 6, p2: 6}`）。任何"降低 MME"的新版本应顺延为 **v7**，不得复用 v6。
2. **门槛不能由观测值倒推**：不应因为**本次测得 0.0804** 就把 MME 改成 0.08——这是**事后改门槛**（[F-13](../reviews/agc-review-2026-10-14/30-未来.md#f-13)），不是工程依据。
3. **"可检测效应"不等于"能通过门槛"**：`N=20 可检测 ≈0.070` 是**双侧检验**在给定 power 下的最小可检测效应，**不**保证"样本均值 ≥ 0.08"的规则能通过。在 legacy `mean ≥ MME` 规则下，真实效应恰等于 MME 时通过概率仅约 **50%**。

## 决策

### (a) 禁止事后降门槛

- P1 v5 的 `inconclusive` **保持不变**；观测到的 0.0804 **不构成** MME=0.08 的依据。
- 没有独立工程依据时，**维持 MME=0.10**，并接受 `inconclusive` / `falsified` 作为结论。

### (b) 若要以更小 MME 立项（**v7**），须同时满足

1. **独立的工程 / 科学价值说明**（写在**新 run 之前**，且**不以本次观测效应为理由**）：说明为何更小的 FCO 提升在任务意义上值得主张（例如对捕获机会 / 任务时长的可解释影响），并给出可检验的预期量级。
2. **新种子（种子隔离）**：**不得**复用参与过场景选择或判据调整的种子——
   - s13/s14/s15/s16 pilot：seeds 0–2；
   - P1 v5：seeds 0–19；
   - P1 机制消融：seeds 0–19。
   ⇒ v7 **SHALL** 使用 **seeds ≥ 20**（或事先声明的另一组未用种子），并写入预注册。
3. **按实际判定规则重新规划样本量**：
   - 三态 CI 规则（v6 起）：`N ≈ ((z_{1−α/2} + z_{1−power}) · σ / (Δ_true − MME))²`（见 [ADR-0086](0086-decision-rule-three-state-ci-versus-mme.md)(d)）；
   - 若仍用 legacy `mean ≥ MME`：需满足 `P(mean ≥ MME) ≥ power`，等价于 `Δ_true ≥ MME + z_{power}·σ/√N`；**不得**用"可检测效应"冒充通过概率。
4. **新预注册版本 v7**：scene / arms / DV / MME / N / α / 种子集**在 run 前写定**；v5 / v6 的结论**不回溯改写**。

### (c) 数值示例（说明"可检测"与"通过门槛"的差别）

以 σ≈0.112、N=20（SE≈0.025）为例：

| 规则 | 要求 | 真实效应 = 0.08 时 |
|---|---|---|
| 双侧检验"能否检测到非零" | 可检测 ≈0.070（80% power） | 可检测到，**但**不等于通过门槛 |
| legacy `mean ≥ 0.08` | 样本均值 ≥0.08 | 通过概率 ≈ **50%**（均值抽样分布以 0.08 为中心） |
| 三态 `CI 下限 > 0.08` | 余量 `Δ_true−0.08` | 需 **N≈246**（余量 0.02）或 **N≈109**（余量 0.03） |

⇒ "N=20 可检测 ≈0.072"**不能**推出"能通过均值≥0.08"；两者是不同的问题。

## 备选

1. **现在把 MME 改为 0.08 并复用 seeds 0–19** —— 否决：事后改门槛 + 种子已被场景选择与判定使用（选择偏差）。
2. **用"N=20 可检测 0.072"作为通过的论据** —— 否决：混淆"可检测效应"与"通过门槛的概率"（(c)）。
3. **维持 MME=0.10、加大 N 取得决断性结论** —— **允许**：不是改门槛；须 v7 新预注册 + 新种子 + 按规则重算 N（N≈109/246，取决于余量）。
4. **不做 v7，保留 `inconclusive`** —— **允许**：若无独立工程依据，这是默认路径。

## 后果

- **正面**：门槛变更不再由观测值驱动；种子隔离消除"场景选择 / 判据调整"的复用偏差；"可检测效应"与"通过门槛"的语义被分清。
- **代价 / 限制**：当前不产生新的 P1 判定；`inconclusive` 维持。若要做 v7，成本按 [ADR-0086](0086-decision-rule-three-state-ci-versus-mme.md)(d) 的 N≈109–246 量级。
- **未决 / 后续**：是否提出独立的工程价值说明（决定 v7 是否立项）；P2 侧消融与 W7-c 仍未执行。

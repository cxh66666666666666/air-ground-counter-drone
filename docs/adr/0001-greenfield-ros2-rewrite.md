# ROS2 全新重写，而非逐包等价迁移

## Status
accepted

## 背景与决策
原《ROS2迁移步骤》假设"逐包等价迁移、保留接口语义"。我们改为：新项目根 = `/home/chen/AGC`（colcon 根即项目根）；ROS2 代码、实验产物、文档三类结构**从零搭建**新规范；ROS1 旧树 `anti_drone_agc_workspace/` **降级为只读归档参照**，仅供 P6 行为对照，不作代码来源。

## Considered Options
- 逐包等价迁移 + 局部优化（原方案）—— 被否：会把旧项目（尤其实验目录）的结构错乱一并继承。

## Consequences
- 旧树在 P6 对照期前须保持可运行；随后移入 `reference/` 或独立裸仓。
- 新代码不得从旧树复制粘贴；只允许读取以对齐行为语义。
- 包边界、目录布局按本项目新规范重新设计（见后续 ADR）。

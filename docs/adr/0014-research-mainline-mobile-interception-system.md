# 研究主线：移动式主动拦截系统（系统论文为主，协同路径规划为核）

## Status
accepted

## 背景与决策
- 论文主线定为 **移动式主动拦截系统**（系统 / 集成论文，D）为主、**空地协同路径规划 / 制导**（A）为核；二者共用本仓库仿真，不另立系统。
- **RL 地面控制（B）** 与 **多源信息融合（C）** **不放弃**，但**归入"项目结束后的后续研究"**——本仓代码与其 workstream（W7 / W4 加深）**不得因此删除**，仅调整本次优先级。

## Considered Options
- 以 RL（B）或融合（C）为**本次**论文主线 —— 被否：本次以系统论文最容易兑现软著 / 平台 / 申报书创新点（见 [ADR-0013](./0013-rewrite-as-deliverable-sim-only.md)）；B / C 降为后续而非放弃。

## Consequences
- 论文素材 = 仿真实验产物（`experiments/`）；软著 = `src/`；两者共用同一份代码与产物，口径不得分叉。
- [ADR-0004](./0004-rl-primary-controller-nav2-safety-layer.md)、[ADR-0003](./0003-nav2-pattern-complete-absorption.md) 仍为**实现约定**，但在论文叙事中**降级为手段**；其"后续研究"地位在 W7 spec 落实。
- **待定**：本次执行范围出口（W6 / W7 / W8）与"地面控制现状"（RL 归后续后 W5/W6 用什么）——由后续 ADR 定夺。

# 捕获裁决口径厘清：现「入包络即命中」为闭式占位，后续以「火控窗口 + 瞄准提前量」为口径

## Status

accepted

## 背景与决策

[ADR-0022](./0022-launched-net-capture-mechanism.md)(c) 定：物理捕获现阶段 = **闭式几何判定**（**发射时刻**判断目标是否落在网发射物理模型的**可及集**内），`capture adjudicator` 可插拔，后续换逐帧弹道判定器。

W6 落地为 `agc_task/capture_adjudicator`（[源码](../../src/agc_task/src/capture_adjudicator.cpp)）：以包络闭式判定，**目标一进入包络即自动置** `INTERCEPT_CONFIRMED`(`CAPTURE_NET`)。核查发现：该实现把 ADR-0022(c) 的「**发射时刻**判定」**偷换成了「入包络即命中」**，带来四点失真：

1. **无发射时刻 / 无瞄准**：真实网捕须选择发射瞬间并打提前量；现规则把「动态拦截」（[ADR-0014](./0014-research-mainline-mobile-interception-system.md)）降维为「接近到 R 米」。
2. **判据用当前水平距离，未计网飞行时间 `t_flight`**：对移动目标，网到位时目标已移位 → 高估命中。
3. **`t_exp`（展开时长）未参与、一次性且无失手 / 冷却**：还不是 ADR-0022 声明的「网发射物理模型」的完整形态。
4. **捕获与干扰共用同一作用包络** → 捕获必先触发，`先命中者胜`（spec R11）**退化**，`jammer` 路径在包络内不可能得终态。

故本次**厘清口径**（不改代码）：

**(a) 现规则保留为 W6 现阶段闭式占位**：`capture_adjudicator` 的「入包络即命中」**仅**用于在批量评估中**产出终态 / 指标**（C8·C9）与联调；**不得**作为最终口径，**不得**据此在报告 / 论文中声称「实现了移动式主动拦截」。

**(b) 后续口径（替换逐帧弹道判定器时）**：以网到达时刻 `t_flight` 的**目标预测位置**判定可达（**瞄准提前量**）；引入**火控窗口**（目标在可及集内**且**几何 / 接近条件许可才发射，而非入包络即命中）；发射后含**失手 / 冷却**；并**分离干扰作用包络**，解开 (a·4) 的退化。

**(c) 该替换在 [ADR-0022](./0022-launched-net-capture-mechanism.md)(c) 预留的**可插拔接口**内完成，**对外不破坏**：最终终态（`INTERCEPT_CONFIRMED` / `reason_code`）与冻结 **9 消息** ABI **不变**，唯一执行口 **不变**。

> **范围澄清**（[ADR-0058](./0058-capture-adjudicator-replacement-contract-and-event-semantics.md) 采纳；挑战原意见 [X-05](../../docs/reviews/agc-review-2026-10-14/10-风险.md#x-05)）：本项「调用方不改」**限定为对外可观测契约**，**不**等于"裁决器无内部事件语义、零实现演进"。真实弹道替换**允许**在**内部**引入 **shot 生命周期**（射击请求 / 发射 / 到达 / 命中 / 失手 / 取消 / 冷却）与异步事件，消费侧可在既有 ABI 内做必要的状态清理与关联（**不**新增第二 ROS 命令者）。执行顺序：**先**完成 R-021 的 episode 隔离与事件身份（[ADR-0036](./0036-capture-event-episode-isolation-and-event-identity.md)），**再**替换弹道判定器。

## Considered Options

- **现状即最终口径** —— 被否：会把「移动式主动拦截」常义化，且与 ADR-0022(c)「发射时刻判定」不符。
- **本轮直接实现火控窗口 / 瞄准提前量** —— 被否：受本次出口（[ADR-0016](./0016-execution-scope-exit-w6.md)）工期约束，留作后续；且会改动已验收的 R9/R11 口径。
- **记录口径 + 保留占位（本 ADR）** —— **采纳**。

## Consequences

- W6 spec `R9` 的「接口稳定、后续弹道判定器替换不改调用方」在本口径下成立；此前记于 [W6 tasks](../../.trae/specs/w6-task-eval/tasks.md) 的**未决项**（捕获 / 干扰共用包络致 `先命中者胜` 退化）据此消解。
- **报告 / 文档纪律**：凡涉及 `CAPTURE_NET` 的表述，须标注「**闭式占位裁决**（非弹道 / 火控）」。
- 后续实施归**后续 workstream**（W6-c 增补或新 workstream）；W8 新旧对照（[ADR-0016](./0016-execution-scope-exit-w6.md)）须注意本口径差异。

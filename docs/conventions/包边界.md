# 包边界

> 本文件定义 `src/` 下各 ROS2 包的职责、构建类型与依赖方向。包边界按**职责域**切分（[ADR-0006](../adr/0006-domain-workstream-organization.md)），不从旧树继承。

## 1. 包清单

| 包 | 职责域 | 对应 WS | 语言 / 构建 | 职责 |
|---|---|---|---|---|
| `agc_msgs` | 接口与消息 | W1 | `ament_cmake` + rosidl | 协同层消息 / 服务 / action 定义（唯一公共接口） |
| `agc_sim` | 仿真世界与模型 | W2 | `ament_cmake` | `agc_world`、车 / UAV 模型、`ros_gz` 桥、传感器链路 |
| `agc_control` | 通用控制层（共享库） | W3 | `ament_cmake` | pluginlib 轨迹生成器 / LQR 控制器插件；接口 `state + ref → acc`，供 air / ground 共用（[ADR-0018](../adr/0018-shared-control-layer-and-lqr-plugin.md)） |
| `agc_air` | 空中链路 | W3 | `ament_cmake` | PX4 uXRCE-DDS 链路、起飞 / 悬停 / LQR 轨迹跟踪、跟随 |
| `agc_perception` | 感知与融合 | W4 | `ament_cmake` | odom / gt / perception / fusion / map 适配节点 |
| `agc_ground` | 地面导航与安全层 | W5 | `ament_cmake` | RL 主控链路、Nav2 `collision_monitor` 安全层、离线基线 |
| `agc_task` | 任务与评估 | W6 | `ament_cmake` | `task_manager`、`agc_run_logger`、场景、评估 |
| `agc_rl` | RL 平台 | W7 | `ament_python` | 策略、训练 / 评估流水线、论文产线 |

第三方包 `px4_msgs`（内联入库，来源于 `github.com/PX4/px4_msgs` 经 gh-proxy，pin 于 `a1045ec` / `release/1.15`）原样置于 `src/`，**不改造**。

## 2. 依赖方向

```
                 agc_msgs   (接口层，叶依赖，无兄弟依赖)
                 ▲ ▲ ▲ ▲ ▲ ▲
      ┌──────────┘ │ │ │ │ └──────────┐
   agc_sim     agc_air  agc_perception  agc_ground  agc_rl
                  │                       │
                  └──> agc_control <──────┘   (共享控制库)
                                            │
                                        agc_task
```

规则：

1. **`agc_msgs` 是唯一公共依赖**，位于依赖图底层，不依赖任何兄弟包。
2. 其余包之间**不得互相依赖对方的库**；跨域通信一律经 `agc_msgs` 定义的 topic / service / action。
   - **例外**：`agc_control` 为**共享控制库**（非业务节点），允许 `agc_air` / `agc_ground` 链接**同一实现**（[ADR-0018](../adr/0018-shared-control-layer-and-lqr-plugin.md)）。
3. 允许的额外外部依赖：`agc_air` → `px4_msgs` + PX4 uXRCE-DDS；`agc_air` / `agc_ground` → `agc_control`；`agc_ground` → Nav2 组件；`agc_sim` → `ros_gz`。
4. **禁止环形依赖**。
5. `agc_task` 作为跨域编排者，只通过接口层协调，不直接链接各域实现库。

## 3. 依赖检查

- `colcon list` 输出包名集合须与上表（包清单）一致（含 `px4_msgs`，共 8 包 + 第三方）。
- 新增包间依赖前，须先确认不违反规则 2 / 4。

# 目录与命名规范

> 本文件是 W0 产出的**工程规范**，约束后续所有 workstream 的命名与目录。
> 约束类信息（坐标系、唯一执行口、参数入口、硬约束）**只引用**契约真源 [ROS2迁移交接文档](../ROS2迁移交接文档.md)，本文件不复述。

## 1. 顶层目录骨架

```
AGC/
├── .trae/specs/<ws>/{spec,tasks,checklist}.md   # per-workstream 规格
├── GLOSSARY.md                                  # 术语
├── docs/
│   ├── ROS2迁移交接文档.md                       # 契约真源
│   ├── ROS2迁移步骤.md                           # Runbook（唯一执行入口）
│   ├── adr/                                     # 决策记录
│   └── conventions/                             # 工程规范（本目录）
├── src/                                         # ROS2 包（colcon 源）
├── experiments/                                 # 实验产物（唯一落点）
├── scripts/                                     # 顶层编排脚本
├── reference/                                   # 归档旧树（只读）
├── toolchain/                                   # 外部仓库 / 工具链（不入库，仅 README）
└── build/ install/ log/                         # colcon 产物（忽略）
```

## 2. 包名

- 本项目自有包统一 `agc_<域>`，全小写、下划线分隔。
- 第三方包原样置于 `src/`，**不改造、不改名**（如 `px4_msgs`）。

## 3. 话题

- 协同层统一命名空间 `/agc/`，形如 `/agc/<域>/<对象>`。
- 既定名以契约真源为准：参数入口见 [参数入口](../ROS2迁移交接文档.md#params)，唯一执行口见 [唯一执行口](../ROS2迁移交接文档.md#execution-port)。

## 4. TF 帧

- 机体系一律 `<实体>/<link>`（如 `drone/base_link`、`car/base_link`），**禁止裸 `base_link`**。
- 依据契约 [命名空间与坐标系](../ROS2迁移交接文档.md#namespace)。

## 5. 参数

- 形如 `/agc/<域>/<名>`，由 launch **单一设置**，节点**不得覆写**。
- 参数入口清单见契约 [参数入口](../ROS2迁移交接文档.md#params)。

## 6. 文件命名

- **源码与配置文件**一律 `snake_case`（如 `task_manager.cpp`、`scenario_params.yaml`）。
- **文档**（`docs/**`、`*.md`）不受此限，沿用中文标题文件名（与既有真源一致）。
- 禁止在文档路径中使用空格。

## 7. 分支

- 每个 workstream 一个分支：`ws/<id>-<slug>`（如 `ws/w0-conventions`）。
- 验收通过后合并回 `main`。

## 8. spec 目录

- 每个 workstream 的规格位于 `.trae/specs/<ws-id>-<slug>/`，三件套 `spec.md` / `tasks.md` / `checklist.md`。
- 详见 [spec模板](./spec模板.md)。

## 9. 构建系统

| 包类型 | 构建系统 |
|---|---|
| C++ 节点包 | `ament_cmake` |
| 接口包（消息 / 服务 / action） | `ament_cmake` + `rosidl_default_generators` |
| Python 包（RL / 工具） | `ament_python` |

各包职责与依赖方向见 [包边界](./包边界.md)。

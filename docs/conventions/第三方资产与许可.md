# 第三方资产与许可

> 本文件是**第三方（外部）资产的来源 / 许可 / 署名 / 内容哈希**的独立清单与政策——人读表 + 机器可读 ```yaml 块。
> 决策真源：[ADR-0068](../adr/0068-third-party-asset-provenance-license-and-hash-manifest.md)（外部资产来源、许可与哈希清单）。
> 上游换装口径：[ADR-0021](../adr/0021-ground-safety-thresholds-and-platform-recalibration.md#third-party-license-note)（地面平台保形换装 + 许可适用关系注）。
> 工具链 pin 清单：[ADR-0065](../adr/0065-toolchain-rebuildable-pin-manifest.md)（**只标工具链 pin，替代不了资产身份**）。
> 引用纪律：跨文档一律用稳定锚点（`<文件>#<锚点>`），**禁止** `§` 章节号。

## 1. 政策

1. **分列、不外推**：自有 ROS 包（`agc_*`）的 `<license>Proprietary</license>` **仅**适用于自有代码，**不得**外推到第三方资产；第三方资产许可**逐资产独立**登记，且**不得**标 `Proprietary`。
2. **保留上游署名**：第三方资产入库时**随附**来源与署名（`NOTICE` 或本清单条目）；上游许可要求保留版权 / 许可声明的（如 `BSD`），**必须**保留。
3. **据实登记，未核实即标注未决**：许可无法当场核实（来源材料未随资产保留）时，**登记候选许可 + 状态 `unresolved`** 并写明理由；**禁止**未经验证地**断言**许可（如在模型注释里写死某许可）。
4. **内容哈希**：逐资产记 `sha256`（资产身份），供 `scripts/third_party_asset_check.py` 独立复核（清单 == 实测哈希）。
5. **正式分发**：对外分发以**版本 / 标签（tag）** + **artifact manifest**（逐文件哈希）为准；本清单是其**资产级**子集。**本轮不**要求变更自有包版本号。

## 5. 正式分发（版本 / tag + artifact manifest）

- **版本 / 标签**：正式分发的对外版本以仓库 **tag**（如 `vX.Y.Z`）标识；tag 名即分发身份。
- **artifact manifest**：分发产物随附**逐文件 `sha256`** 的 manifest（可用 `git archive` + 哈希清单生成）；本文件「机器可读清单」节是其**第三方资产级**子集，工具链 pin 由 [ADR-0065](../adr/0065-toolchain-rebuildable-pin-manifest.md) 覆盖。
- **本轮**：**不**实建 tag、**不**变更自有包版本号（`0.0.0` / `Proprietary` 保留）；仅**政策成文**。

## 6. 未决与后续

- **Fuel 资源 id / 下载版本 / 随附 LICENSE 文本 未取回** → 本清单相应字段记为 `null` / **未决**，许可状态 `unresolved`，候选 `BSD`。取回后回填并置 `license_status: resolved`（**不**静默断言）。
- **`CC0` vs `BSD` 事实**：仓内旧注释自称 `CC0 v1.0`（**未经验证**）；上游 Clearpath Husky ROS 资产族（`husky_description` / `husky_gazebo` / `clearpath_gz`）在 ROS Wiki / ROS Index 标 **`BSD`**（要求保留署名）。→ 据实登记为**候选 `BSD` + 未决**。
- 后续**新增**第三方资产**须**在同一清单 + `NOTICE` 登记（**先登记后入库**），并由 `scripts/third_party_asset_check.py` 复核。

# 实验产物规范

> 决策真源：[ADR-0007](../adr/0007-experiment-artifacts-convention.md)。本文件是其**操作化落盘规则**，不复述约束。

## 1. 唯一落点与结构

所有实验产物**只**落 `experiments/`，按 `campaign → run` 两层组织：

```
experiments/<campaign>/<run_id>/
├── config/     本次参数快照（必需，可复现）
├── bag/        ros2 bag
├── log/        运行日志 / run logger 输出
├── metrics/    结构化指标
└── figures/    出图
```

`run_id = <YYYYMMDD>-<scenario>-<seed>`。

## 2. 落盘要求

- 每次 run **必须**落 `config/` 参数快照 + git commit hash。
- **禁止**在其它任何位置写实验产物。

## 3. 版本控制规则

依据根 `.gitignore`：

- **入库**：`experiments/README.md` 与各 run 的 `config/**`。
- **忽略**：`bag/`、`log/`、`metrics/`、`figures/` 及其它任何产物。

> 校验命令：`git check-ignore -v experiments/<c>/<run>/bag` 应命中；`.../<run>/config/params.yaml` 应**未**命中。

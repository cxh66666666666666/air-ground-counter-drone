# 实验产物规范

> 决策真源：[ADR-0007](../adr/0007-experiment-artifacts-convention.md)（唯一落点）与
> [ADR-0044](../adr/0044-unique-run-identity-and-reproducible-evidence.md)（唯一 run 身份与可复现证据）。
> 本文件是其**操作化落盘规则**，只索引不复述约束。

## 1. 唯一落点与结构

所有实验产物**只**落 `experiments/`，按 `campaign → run` 两层组织：

```
experiments/<campaign>/<run_id>/
├── config/     本次参数快照与运行身份（必需，可复现，入库）
├── metrics/    结构化指标（含 campaign 汇总报告）
├── bag/        ros2 bag
├── log/        运行日志 / run logger 输出
└── figures/    出图
```

- **episode run_id**：`<YYYYMMDD>-<scenario>-<seed>-<HHMMSS>-<rand4>`（唯一、独占创建；格式与语义以 [ADR-0044](../adr/0044-unique-run-identity-and-reproducible-evidence.md) 为准）。
- **campaign run_id**：`<YYYYMMDD>-<campaign>-<HHMMSS>-<rand4>`（同日同 campaign 连跑落到不同目录，**不**覆盖）。
- campaign 汇总报告落该 campaign run 的 `metrics/report.{json,md}`，并**引用**每个 episode run 的不可变产物（`run_id` + `config/`）。

## 2. 落盘要求

- 每次 run **必须**落 `config/` 快照与运行身份（见 [ADR-0044](../adr/0044-unique-run-identity-and-reproducible-evidence.md)）：展开参数
  `params_applied.yaml`、`scene_manifest.json`、代码身份（`git_*.txt` / `git_diff.patch` /
  `workspace_fingerprint.json`）、工具链与世界哈希（`toolchain_world.json`）、`episode_id.txt`。
- **禁止**在其它任何位置写实验产物。

## 3. 版本控制规则

依据根 `.gitignore`：

- **入库**：`experiments/README.md` 与各 run 的 `config/**`。
- **忽略**：`bag/`、`log/`、`metrics/`、`figures/` 及其它任何产物。

> 校验命令：`git check-ignore -v experiments/<c>/<run>/bag` 应命中；`.../<run>/config/params.yaml` 应**未**命中。

## 4. 证据归档与入库 manifest

> 决策真源：[ADR-0064](../adr/0064-evidence-immutable-archive-and-intake-manifest.md)。本文件只索引不复述约束。

- 每 run 生成**入库 manifest** `config/evidence_manifest.json`（逐产物 `sha256` / 大小 / 类型 + 运行身份
  `run_id`/`episode_id`/`git_commit`/`backend` + 生成器版本 + **访问位置**（归档路径）+ **保留期**）。
- 每 run 打包为**本地不可变归档** `experiments/_archive/<campaign>/<run_id>.tar`（含 manifest、**只读 0444**）
  + 同名 `.tar.sha256` + `.tar.retrieval.json`；`experiments/_archive/` **不入 git**（大归档 / 大 `bag`）。
- 工具：`python3 scripts/evidence_archive.py`（`--campaign`/`--run-id` 过滤、`--force` 重建、`--list` 枚举），
  默认做**跨路径取回验证**（解包到**另一路径**逐文件哈希比对，证明「可取回」）。
